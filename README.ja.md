## 📖 概要

HSM Kit は、金融・決済・セキュリティ分野の開発者、テスター、セキュリティエンジニア向けに設計されたプロフェッショナルオンライン暗号化ツールキットです。HSM鍵管理、決済セキュリティ、PKI証明書、暗号化アルゴリズムをカバーする44+ツールを提供し、すべてブラウザ内で動作します。

## ✨ 主な機能

- **44以上のブラウザ内ツール** — 鍵、PIN、入力データ、結果はサーバーへ送信されません
- **セキュリティ知識ベース** — 英語42記事・中国語42記事を静的配信
- **安全なサンプル読込** — 選択中のモード、形式、タブ、切替状態を変更しません
- **統一入力検証** — すべてのツールで長さ・形式をグレー／緑／赤で表示
- **お気に入り・最近使ったツール** — アカウント不要でブラウザ内に保存
- **オープンソース** — 90件以上のユニットテストと全44ツールのページチェック
