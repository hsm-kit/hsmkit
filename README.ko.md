## 📖 소개

HSM Kit은 금융, 결제, 보안 분야의 개발자, 테스터, 보안 엔지니어를 위해 설계된 전문 온라인 암호화 도구 키트입니다. HSM 키 관리, 결제 보안, PKI 인증서, 암호화 알고리즘을 다루는 44개 이상의 도구를 제공하며, 모두 브라우저에서 실행됩니다.

## ✨ 주요 기능

- **44개 이상의 브라우저 도구** — 키, PIN, 입력값 및 결과를 서버로 전송하지 않습니다
- **보안 지식 베이스** — 영어 43편과 중국어 43편을 정적 페이지로 제공
- **안전한 예제 불러오기** — 현재 모드, 형식, 탭 및 활성화 상태를 변경하지 않습니다
- **일관된 입력 검증** — 모든 도구에서 길이와 형식을 회색/초록/빨강으로 표시
- **즐겨찾기 및 최근 도구** — 계정 없이 브라우저에 로컬 저장
- **AI 친화적 문서** — `llms.txt`, 구조화된 도구 목록, 모든 가이드의 Markdown 버전 제공
- **현지화 도구 및 테스트 벡터** — 8개의 중국어 canonical URL과 실행 가능한 AES JSON 벡터
- **오픈 소스** — 100개 이상의 단위 테스트와 44개 전체 도구 페이지 검사
